# Week 1: Dark Patterns Skill Content

This folder holds the source content for an AI skill that keeps the features we build free of
dark patterns (deceptive design).

- [dark-patterns-skill-content.md](dark-patterns-skill-content.md): the full draft, organized
  into what dark patterns are, how they are used, how to avoid them, when honest persuasion is
  allowed instead, what developers must decide, and what the skill will detect and block.

Status: draft for review. Once approved, this content becomes the body of the skill.

Sources are listed at the end of the content file, each with an evidence note. Two items (the
FTC and EDPB category lists) were taken from secondary summaries and should be confirmed
against the primary documents before the content is treated as final.
